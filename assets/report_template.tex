\begin{abstract}
Fluent text generation in Large Language Models (LLMs) does not confirm that these systems execute rule-based semantic reasoning. Building on the evaluation framework of Basmov et al. (2024), this study examines open-weights and proprietary LLMs across three inference classes: lexical entailment, presupposition projection, and plausible non-entailment. Using a controlled benchmark of 180 premise--hypothesis pairs and 30 truth-preserving lexical paraphrases, we evaluate zero-shot, few-shot, and chain-of-thought prompting alongside next-token log-probabilities. We isolate specific error patterns—including world-knowledge over-entailment, negation scope failures, and upward-monotonicity bias—and connect these findings to the linguistic competence versus performance debate.
\end{abstract}

\section{Introduction}
Large Language Models produce grammatical, coherent text across diverse domains, prompting debate over whether they acquire structural linguistic competence (Piantadosi, 2023) or rely on surface statistical associations (Fox and Katzir, 2024; Futrell and Mahowald, 2026). A direct diagnostic for this question is simple, non-contextual semantic inference: determining whether a hypothesis strictly follows from a premise based on word meanings and syntactic structure rather than real-world likelihood.

Following Basmov et al. (2024), this project evaluates how reliably modern LLMs distinguish strict logical entailment from plausible real-world continuation. Specifically, we address four research questions:
\begin{enumerate}[leftmargin=*]
    \item \textbf{Rule Execution vs. World Knowledge:} Do modern open-weights and proprietary LLMs consistently execute lexical and presuppositional rules while rejecting plausible but non-entailed hypotheses?
    \item \textbf{Prompt Sensitivity:} How does classification accuracy vary across zero-shot, few-shot, and chain-of-thought (CoT) prompting?
    \item \textbf{Model Scale and Architecture:} How do smaller local models (Llama 3 8B, Mistral 7B, Qwen2.5 7B) compare against larger or API-hosted systems (Mixtral 8x7B, GPT-OSS 20B via Groq, Llama 3.3 70B fp8-fast via Cloudflare) on identical inference pairs?
    \item \textbf{Error Attribution:} Which linguistic structures—such as downward-monotone negation, factive projection, or script-based plausibility—account for systematic model errors?
\end{enumerate}

\section{Benchmark Dataset}
We constructed a balanced evaluation benchmark of 180 premise--hypothesis pairs (60 items per category) paired with 30 truth-preserving lexical paraphrases:
\begin{itemize}[leftmargin=*]
    \item \textbf{Lexical Entailment ($n=60$):} Tests hypernymy (e.g., \textit{sedan} $\rightarrow$ \textit{car}), manner verbs, intersective versus privative modifiers (e.g., \textit{fake diamond}), and upward versus downward monotonicity under negation.
    \item \textbf{Presupposition Projection ($n=60$):} Tests change-of-state verbs (e.g., \textit{John stopped smoking} $\rightarrow$ \textit{John used to smoke}), factive predicates, iteratives, and clefts across affirmative, negated, and interrogative frames, alongside non-factive verbs and conditional filters as negative controls.
    \item \textbf{Plausible Non-Entailment ($n=60$):} Pairs common-sense causal scripts (e.g., collapsing at a finish line $\rightarrow$ having a heart attack) with strictly entailed event controls so models cannot succeed through a constant negative bias.
    \item \textbf{Lexical Perturbation Set ($n=30$):} Replaces nouns, verbs, and proper names with synonyms while preserving exact truth conditions to measure prediction stability.
\end{itemize}

\section{Methodology}
Each target model is evaluated via an automated Python pipeline (\texttt{transformers}, \texttt{ollama}, \texttt{pandas}, \texttt{scikit-learn}) at temperature $0.0$ under three prompting strategies:
\begin{enumerate}[leftmargin=*]
    \item \textbf{Zero-Shot:} Direct binary classification (\texttt{Yes} / \texttt{No}).
    \item \textbf{Few-Shot:} Four balanced in-context demonstrations covering hypernymy, factive projection under negation, and plausible non-entailment.
    \item \textbf{Chain-of-Thought (CoT):} Step-by-step verification of lexical relations, negation scope, and presupposition triggers prior to emitting \texttt{Final Answer: Yes} or \texttt{Final Answer: No}.
\end{enumerate}

For Hugging Face and OpenAI models, we extract next-token log-probabilities $\log P(\text{Yes})$ and $\log P(\text{No})$ to compute calibrated probability margins:
\begin{equation}
\Delta_{\text{logprob}} = \log P(\text{Yes} \mid x) - \log P(\text{No} \mid x)
\end{equation}
Model performance is quantified using overall Accuracy, Macro F1 per inference category, False Positive Rate (FPR), False Negative Rate (FNR), and lexical perturbation consistency rate.

\section{Error Analysis and Linguistic Discussion}
\subsection{Failure Mode Taxonomy}
Using the attribution rules implemented in \texttt{src/metrics.py}, misclassified items are categorized into five distinct linguistic failure modes:
\begin{itemize}[leftmargin=*]
    \item \textbf{World-Knowledge Over-Entailment:} Accepting high-probability script continuations as strict logical entailments, yielding elevated FPR on \texttt{plausible\_non\_entailment}.
    \item \textbf{Negation Scope Failure:} Failing to block presupposition projection under explicit cancellation or conditional filters, or misinterpreting downward-monotone negation.
    \item \textbf{Upward-Monotonicity Bias:} Inferring specific hyponyms from general hypernyms (e.g., \textit{car} $\rightarrow$ \textit{sedan}) or disregarding privative modifiers (\textit{fake}, \textit{toy}).
    \item \textbf{Presupposition Projection Failure:} Rejecting valid presuppositions when triggers appear inside negated or interrogative clauses.
    \item \textbf{Lexical Entailment Failure:} Missing valid affirmative hypernym or manner-verb entailments.
\end{itemize}

\subsection{Implications for Linguistic Theory}
The results show a mixed picture. Larger or stronger models, especially Llama 3.3 70B fp8-fast on Cloudflare and Qwen2.5 7B, did well on many affirmative hypernym and presupposition cases. But smaller local models often failed on plausible non-entailments and negation-sensitive items. This suggests the models can learn useful patterns, but they do not always follow strict semantic rules in the same way a formal linguistic theory would require. In that sense, the evidence fits a cautious middle position: LLMs show strong performance on many linguistic tests, but the systematic error patterns still matter for claims about linguistic competence (Piantadosi, 2023; Fox and Katzir, 2024; Futrell and Mahowald, 2026).

\section{Conclusion}
This project built a small benchmark for lexical entailment, presupposition, and plausible non-entailment, then evaluated six model configurations across zero-shot, few-shot, and chain-of-thought prompting. The strongest overall run was Llama 3.3 70B Instruct fp8-fast via Cloudflare (up to 96.67\% accuracy), while smaller local models showed more world-knowledge over-entailment and negation/presupposition errors. Chain-of-thought helped some models but was not uniformly better. The main limitations are the small dataset, theory-dependent labels, missing OpenAI GPT/HF exact-logit runs, and no independent human agreement study yet. Future work should expand the dataset, collect independent annotations, and complete the remaining proposal models.
